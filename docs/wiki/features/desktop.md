# Desktop Integration

## Overview

When FlightDeck is active, CARINA OS applies visual branding to the desktop environment to maintain a consistent mission-control aesthetic.

## Current Desktop Theming (Sprint 1)

Sprint 1 GUI theming includes:
- GNOME default dark mode
- Custom wallpaper (`carina-void.jpg`)
- Accent color applied where supported

## CARINA Color System

| Name | Hex | Usage |
|------|-----|-------|
| Carina Void | `#050814` | Primary background |
| Carina Abyss | `#0A0F2A` | Panels, secondary background |
| Carina Indigo | `#2B2F77` | Structure, depth |
| Carina Electric Blue | `#1FA2FF` | Navigation, calm actions |
| Carina Magenta | `#B14CFF` | Energy, alerts, AI indicators |
| Carina Cyan | `#3DE8FF` | Action, active states |
| Carina Text Primary | `#E6ECFF` | Primary text |
| Carina Text Muted | `#9AA3C7` | Secondary text, hints |
| Carina Divider | `#1C2340` | Borders, separators |

## Design Rules

- **No pure black. No pure white.** Everything lives in the "space light" range.
- Cyan = action / active
- Magenta = energy / alert / AI
- Blue = navigation / calm
- Gradients only left-to-right or radial (never vertical)

## Future Sprints

Planned desktop enhancements:
