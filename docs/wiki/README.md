## What is CARINA OS?

CARINA OS is a headless-first, Debian-based operating system layer built on top of Ubuntu LTS. It provides its own identity, tooling, and profiles while maintaining full compatibility with the Ubuntu ecosystem.

### Key capabilities

- **Profile-based configuration** — Apply purpose-built system profiles (Core, FlightDeck, MissionLab)
- **Sandbox environments** — Fast, disposable containers for safe experimentation
- **MissionLab** — First-class embedded development and robotics tooling
- **CARINA Control** — AI advisory system with confirm-to-execute safety model
- **FlightDeck** — Optional GUI with XFCE/xRDP desktop access
- **Platform agnostic** — Works on EC2, local VMs, laptops, and Toughbooks

### Current release

**CARINA OS v0.2.0** — Sandbox and MissionLab foundations complete.
